Deskripsi
Proyek REST API Perpustakaan merupakan aplikasi pengelolaan data perpustakaan yang terdiri dari backend dan frontend. Aplikasi ini digunakan untuk mengelola data buku dan kategori.

Fitur
1. Dashboard
2. Pengelolaan data buku
3. Pengelolaan data kategori
4. REST API menggunakan PHP
5. Frontend aplikasi perpustakaan

Cara Menjalankan Proyek

Backend
1. Buka terminal Git Bash.
2. Jalankan backend menggunakan PHP.
3. Pastikan backend berjalan pada localhost:8000.

Frontend
1. Buka terminal baru.
2. Jalankan frontend.
3. Buka aplikasi melalui localhost:3000.
